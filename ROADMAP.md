# Roadmap

Beta acceptance is per model, backend and machine. Remaining work includes verified complete split-file loading/download sets, projector association and multimodal acceptance, real embedding/audio models, additional managed backend implementations, GPU device selection beyond the first verified NVIDIA device, Vulkan/NPU backends where actual support exists, and resource-aware independent concurrent sessions.

Connector work includes broader Codex coding/tool compatibility, stricter model tool-count following, approved external STDIO MCP clients, richer DRAGONHYDRA analysis endpoints when a live service is available, and explicit approval checkpoints inside multi-provider workflows. Live paid provider connections require owner-supplied credentials and per-request approval; mocks do not substitute for them.

Physical USB/removable-media testing, additional Windows x64 machines, signed releases, accessibility/scaling coverage, Romanian/German translations and measured tuning beyond the bounded candidates remain future acceptance targets. No future item is presented as a verified beta capability.
