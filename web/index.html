Getting started
  1. Add a GGUF file from its current drive using the native file picker or an absolute path.
  2. Inspect its identity and verify the file once. A readable header alone does not prove inference compatibility.
  3. Run Auto Calibrate to measure bounded CPU/GPU candidates. Or launch a conservative SAFE profile.
  4. Open AI Chat. Start another registered model to switch; ABH unloads the previous engine.
Models and auxiliary files
Each model has its own capability evidence. Embeddings use their own API. Projectors are not standalone chat models. Split files are detected; split loading and multimodal inference remain unsupported in this beta.
Calibration and recovery
SAFE prioritizes conservative settings. BALANCED and FASTEST TESTED come from successful measurements. Changing the model, engine, hardware or driver invalidates measured profiles. A failed GPU load can fall back to CPU. Cancel stops calibration; Stop model releases the owned process.
USB and external drives
Keep the application folder together. Models can stay external. Stop inference before unplugging a drive. If its drive letter changes, choose Reconnect and select the same file; ABH verifies its full hash. Registry removal does not delete weights.
Hugging Face
Inspect a repository, choose an exact file and your storage destination, then download. Pause retains a partial file. Select the same pinned identity to resume. Existing files are never silently replaced.
API keys, Codex and MCP
Generate scoped local keys in API Gateway. The service binds only to 127.0.0.1. Codex uses its real App Server protocol and a separate profile. Function namespaces are translated without discarding identifiers; custom tools are rejected. MCP exposes registered models, not arbitrary files or commands.
Cloud providers
OpenAI, Claude and Grok use separate provider credentials. Enter them in the encrypted vault and explicitly approve each outbound message. A ChatGPT subscription or Codex login is not a general API key. Provider mocks do not prove a live paid connection.
Troubleshooting
Check Diagnostics for engine errors. Verify free RAM, current drive availability and the selected runtime. Try SAFE after a GPU error. Recalibrate after material changes. Installed settings use your writable application-data folder; portable settings use data/ beside the executable.
